# Deploy to Production

Operate Dex applications and servers safely in production.

- [Application operation](/production/application-operations) — Worker health,
  read-only debugging, recovery, and Flow-code versioning
- [Pull Workers](/production/pull-workers) — outbound Worker connections,
  routing, capacity, and shutdown
- [Dex Web](/production/dex-web) — v1 run search and the v2 Run and Work Queue workspaces
- [Server operation](/production/server-operations) — deployment,
  configuration, storage, and Dex Web access control
- [Metrics](/production/metrics) — built-in Dex Server metric catalog and
  Prometheus queries
- [Custom Attribute Store](/production/attribute-store) — SQL warehouses,
  MongoDB, and Redis projection, schema contracts, and retry semantics
