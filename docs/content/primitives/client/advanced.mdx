## Wait for an Attribute match

**WaitForAttributeMatch** waits until an Attribute satisfies a typed scalar comparison and returns the matched current value. It targets the current active run. For an AttributeMap, also supply the instance.

String and Boolean values support equal and not-equal. Integer and floating-point values also support greater-than, greater-than-or-equal, less-than, and less-than-or-equal. A missing Attribute never matches.

Use an application-owned revision Attribute when callers need to refresh after state changes. Wait for a value greater than the last revision, then invoke a Describe or read RPC. Revision is a watermark: rapid changes may be coalesced into one returned value.

<SdkTabs examples={{python: 'examples/python/dex_examples/products/job-post/controller.py', go: 'examples/go/products/job-post/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/products/jobpost/JobPostingController.java', typescript: 'examples/typescript/src/products/job-post/controller.ts', rust: 'examples/rust/src/products/job_post/controller.rs'}}>
<SdkSnippet lang="python">

```python
revision = await app_state.client.wait_for_attribute_match(
    flow_id,
    app_state.job_post.update_version,
    AttributeMatch.greater_than(required_int_query("lastRevision")),
    timedelta(seconds=30),
)
```

</SdkSnippet>
<SdkSnippet lang="go">

```go
var revision int
err = controller.client.WaitForAttributeMatch(
	request.Request.Context(),
	flowID,
	UpdateVersion,
	sdk.AttributeMatchGreaterThan(lastRevision),
	&revision,
)
```

</SdkSnippet>
<SdkSnippet lang="java">

```java
final int revision = client.waitForAttributeMatch(
        workflowId,
        flow.updateVersion,
        AttributeMatch.greaterThan(lastRevision),
        Duration.ofSeconds(30));
```

</SdkSnippet>
<SdkSnippet lang="typescript">

```typescript
const revision = await client.waitForAttributeMatch(
  workflowId,
  jobPostingFlow.updateVersion,
  AttributeMatch.greaterThan(lastRevision),
  30_000,

```

</SdkSnippet>
<SdkSnippet lang="rust">

```rust

    &flow_id,
    &UPDATE_VERSION,
    AttributeMatch::greater_than(query.last_revision),

```

</SdkSnippet>
</SdkTabs>

Object, bytes, null, blob-backed, non-finite floating-point, cross-type, and invalid ordering comparisons are rejected. The wait is available with Temporal only; Cadence returns Unimplemented. See [Wait for Attribute Match](/design-patterns/responsive-update/attribute-match) for the complete revision pattern.

## Search Flows

**SearchFlows** returns one page of Flow runs matching a visibility query. Search finds Flow instances; **DescribeFlow** describes one known Flow ID. Pass the returned page token to continue a search.
