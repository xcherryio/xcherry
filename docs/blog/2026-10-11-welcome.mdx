This blog is where we write about building and running durable processes with Dex: what we built, what broke, and what we learned.

{/* truncate */}

Expect three kinds of posts:

- **Build notes.** A real process we built with Dex, the design decisions behind it, and the failures it had to survive.
- **Process engineering.** How long-running processes with waits, approvals, retries and hand-offs should be designed, argued from one concrete example.
- **Process walkthroughs.** One recognizable business process taken apart: its steps, where it usually breaks, and a design that holds up.

Every post aims to be useful even if you never run Dex. When one helps, tell us about a process you are struggling to run reliably.
