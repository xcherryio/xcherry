## 等待 Attribute 匹配 {#wait-for-an-attribute-match}

**WaitForAttributeMatch** 等待 Attribute 满足类型化的 scalar 比较，并返回当前命中的值。它定位当前 active run。对于 AttributeMap，还需要传入 instance。

String 和 Boolean 支持 equal 与 not-equal。整数和浮点数还支持 greater-than、greater-than-or-equal、less-than 与 less-than-or-equal。缺失的 Attribute 永远不命中。

当调用方需要在状态变化后刷新时，使用应用拥有的 revision Attribute。等待 revision 大于上次观察到的值，再调用 Describe 或 read RPC。Revision 是 watermark；快速变化可能合并为一个返回值。

<SdkTabs examples={{python: 'examples/python/dex_examples/products/job-post/controller.py', go: 'examples/go/products/job-post/controller.go', java: 'examples/java/src/main/java/io/superdurable/dex/products/jobpost/JobPostingController.java', typescript: 'examples/typescript/src/products/job-post/controller.ts', rust: 'examples/rust/src/products/job_post/controller.rs'}}>
<SdkSnippet lang="python">

```python
    timedelta(seconds=30),
)
```

</SdkSnippet><SdkSnippet lang="go">

object、bytes、null、blob-backed、非有限浮点、跨类型比较和无效 ordering 比较会被拒绝。该等待只支持 Temporal；Cadence 返回 Unimplemented。完整 revision 模式见[等待 Attribute 匹配](/design-patterns/responsive-update/attribute-match)。
